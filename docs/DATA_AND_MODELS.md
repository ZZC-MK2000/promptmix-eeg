# Data, caches and model weights

This repository publishes **code, figures and small public result JSONs**. Raw EEG/audio,
derived embedding caches and pretrained weights are not redistributed.

## Why not

- NMED-T / NMED-H raw EEG and the commercial stimuli are subject to dataset terms and
  copyright; derived caches encode the same signals.
- Pretrained checkpoints (LaBraM, CLAP, MERT, MusicGen, Qwen2-Audio) are hundreds of MB
  to tens of GB and have their own licenses.

The scripts fail loudly or print a missing-path message if an asset is absent.

## Expected layout

```
promptmix-eeg/
├── data/
│   └── eegcond/                 # cond.npy, codes.npy, group.npy, meta.json
├── vendor/
│   ├── mainv2/
│   │   ├── data/                # gate_nmedh14_ov2_a.npz, gate_nmedh14_ov2_uv16.npy,
│   │   │                        # nmedt_env_secs.npz, nmedt_pretrain_ckpt.pt
│   │   └── results/             # eeg_to_clap_proj.pt, align_ladder_result.json
│   ├── models/
│   │   └── musicgen-small/      # or set MUSICGEN_DIR
│   └── LaBraM-main/             # external LaBraM code + checkpoints/labram-base.pth
├── data_external/
│   └── fma_small/fma_small/     # retrieval distractor pool (optional)
└── results/                     # generated by the scripts; not committed
```

The analysis scripts use their own `ROOT` / `M2` constants. The intended public
layout is the sibling `mainv2/` directory (as in the original workspace); either keep
that layout or point the constants at the paths above. The shell drivers accept
`MAINV2_DIR`.

## Environment variables

| variable | meaning |
|---|---|
| `MAINV2_DIR` | workspace holding `data/` and `results/`; used by `run_subject_holdout.sh` / `run_block_control.sh` / `eval_subject_holdout.py` |
| `MAINV2_DATA` | override the cache directory |
| `MAINV2_RESULTS` | override the result directory |
| `NMEDT_ROOT` | raw NMED-T root, if a script needs it |
| `LABRAM_DIR` | LaBraM code directory (contains `modeling_pretrain.py`) |
| `LABRAM_CKPT` | `labram-base.pth` |
| `MUSICGEN_DIR` | local MusicGen-small directory |
| `FMA_DIR` | FMA-small distractor pool |

## Models

- **LaBraM-Base** — external code and `labram-base.pth`; the vendored
  `encoder_labram.py` imports `modeling_pretrain` from `LABRAM_DIR`.
- **laion/clap-htsat-unfused** — HuggingFace CLAP audio/text towers (cached by
  `transformers`).
- **MERT-v1-95M** — per-second audio targets (HuggingFace).
- **facebook/musicgen-small** — frozen generator.
- **Qwen2-Audio-7B-Instruct** — free-text captioner (4-bit local checkpoint used for
  the caption comparisons).

## Commands

```bash
pip install -r requirements.txt

export MAINV2_DIR=/path/to/mainv2-with-data
export LABRAM_DIR=/path/to/LaBraM-main
export LABRAM_CKPT=$LABRAM_DIR/checkpoints/labram-base.pth

# core listener results
python code/information/info_ladder.py
python code/information/oracle_alignment.py
python code/information/k_shot_calibration_v2.py

# subject-held-out retrain + control
bash code/information/run_subject_holdout.sh
python code/information/eval_subject_holdout.py
bash code/information/run_block_control.sh
```

## Privacy

Do not commit `data/`, `vendor/mainv2/data/`, `vendor/mainv2/results/`, model
checkpoints or generated embedding caches. `.gitignore` excludes raw data, `.npy`,
`.npz`, `.pt`, `.wav` and logs; the public tree contains only code, figures and the
small `results/public/` JSONs used by the webpage.
